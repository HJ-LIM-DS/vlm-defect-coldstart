# 연구 설계와 판정 기준 (결과를 보기 전에 기록)

상태: 2026-11-01 확정. 첫 모델을 돌리기 전에 커밋했다. 이 파일의 가설과 판정 기준은 결과를 본 뒤 고치지 않는다. 고쳐야 할 사정이 생기면 "변경 기록" 절에 날짜와 이유를 남긴다.

## 1. 동기

제조 현장에서 검사 모델은 제품이 바뀔 때마다 새로 만들어진다. 새 제품의 결함 라벨은 처음에 없고, 있는 것은 품질 담당자가 아는 결함의 이름과 설명뿐이다. 이 상황을 콜드 스타트라고 부른다. 비전 언어 모델(VLM)은 이미지와 글을 함께 읽으므로, 다른 제품에서 배운 결함 어휘를 처음 보는 제품에 글로 옮길 수 있을 가능성이 있다. 이 프로젝트는 그 가능성을 비-VLM 방법과 같은 조건에서 재고, VLM의 이득이 라벨 몇 장까지 유지되는지 경계를 긋는다.

## 2. 연구 질문

| 번호 | 질문 |
|---|---|
| Q1 | 다른 제품들로 LoRA 적응한 VLM에 새 제품의 결함 사전(유형 이름과 한 줄 정의)만 주면, 라벨 없이 결함 유형을 맞히는가 |
| Q2 | 새 제품의 라벨을 몇 장 모으면 전문 few-shot 분류기가 VLM을 따라잡는가(교차점 k) |
| Q3 | VLM은 사전의 정의 문장을 실제로 읽는가, 아니면 이름만으로 맞히는가 |
| Q4 | 라벨이 충분한 조건에서는 어느 쪽이 나은가(VLM에 불리할 것으로 예상하는 대조군) |

## 3. 데이터

MVTec AD(Bergmann et al., CVPR 2019, IJCV 2021)를 쓴다. 제품 15개(텍스처 5, 객체 10), 학습용 정상 3,629장, 테스트 정상 467장, 테스트 결함 1,258장, 결함 유형 73개다. 각 결함 이미지에는 유형 폴더와 픽셀 마스크가 있다. 이미지는 저장소에 넣지 않고(CC BY-NC-SA 4.0) 인덱스(`data/index.csv`)만 남긴다. 아래 장수는 공식 아카이브를 `src/data/index_mvtec.py`로 세어 확인한 값이다.

### 결함 사전

`lexicon/mvtec_ad.yaml`에 제품별 정상 규격 한 문장과 결함 유형별 한국어 이름, 한 줄 정의를 적었다. 작성 근거는 폴더 이름과 원 논문의 서술뿐이고 테스트 이미지는 보지 않았다. 사전은 첫 모델을 돌리기 전에 커밋하고 그 뒤 고치지 않는다.

유형의 공통/고유 구분은 키(폴더 이름) 일치로만 계산한다. 같은 키가 두 제품 이상에 있으면 공통, 한 제품에만 있으면 고유다. 공통 키는 14개(bent, color, combined, contamination, crack, cut, faulty_imprint, glue, hole, metal_contamination, poke, rough, scratch, thread)이고, 제품과 키의 쌍으로 세면 공통 39개, 고유 34개다. 유형별 장수는 `data/lexicon_coverage.csv`로 확정한다. 이름이 비슷하지만 키가 다른 쌍(scratch와 scratch_head 등)은 고유로 둔다. 이 결정이 공통 유형의 전이 효과를 과소평가할 수 있다는 점은 한계에 적는다.

### 제품 분할

제품 단위 5-fold다. fold에 든 3개 제품은 학습에서 완전히 빠지고, 그 fold를 평가할 때 결함 사전과 정상 이미지만 주어진다. 배치 규칙은 `src/data/splits.py`에 있다: 텍스처는 알파벳 순으로 fold 1~5에 하나씩, 객체는 fold마다 둘씩, 모든 공통 키는 어느 fold를 평가하든 학습 측에 남아야 하며, 조건을 만족하는 배치 중 사전순 첫 번째를 고른다. 결과는 `data/splits.csv`다.

| fold | 제품 |
|---|---|
| 1 | bottle, cable, carpet |
| 2 | capsule, grid, hazelnut |
| 3 | leather, metal_nut, pill |
| 4 | screw, tile, toothbrush |
| 5 | transistor, wood, zipper |

### 평가 제품에서 쓸 수 있는 것

| 자원 | 사용 여부 |
|---|---|
| 결함 사전(이름, 정의, 정상 규격) | 모든 방법에 제공 |
| train/good 정상 이미지 | 정상 참조 선택, 탐지기 메모리 뱅크, 정상 기준 특징에 사용 |
| test/good 정상 이미지 | 평가에만 사용(정상 판정률) |
| test 결함 이미지와 유형 라벨 | VLM과 라벨 0장 기준선에는 주지 않음. few-shot 분류기에는 유형당 k장만, 전체 라벨 대조군에는 교차 검증으로 사용 |

## 4. 과제와 출력

입력은 검사 이미지 한 장과 그 제품의 결함 사전이다. 출력은 두 줄이다.

```
유형: <사전의 한국어 이름 중 하나, 또는 정상>
근거: <한 문장>
```

주 과제는 결함 이미지의 유형 분류다. 정상 이미지도 같은 프롬프트로 넣어 "정상"이라고 답하는 비율을 함께 잰다. 유형 이름이 사전에 없으면 형식 위반으로 집계하고 틀린 것으로 채점한다.

### VLM 입력 구성

- 검사 이미지
- 이상 영역 crop: 평가 제품의 train/good으로 만든 PatchCore 메모리 뱅크(WideResNet-50 특징)의 이상 맵에서 가장 높은 영역을 잘라 낸 것. 라벨이 필요 없다.
- 정상 참조 1장: 같은 제품 train/good 중 DINOv2 특징이 가장 가까운 이미지
- 글: 제품 이름과 정상 규격, 결함 유형 목록(이름과 정의, 순서는 이미지마다 무작위)

## 5. 비교 대상

| 기호 | 방법 | 새 제품 라벨 | 역할 |
|---|---|---|---|
| Z | Qwen3-VL-4B zero-shot, 사전 포함 프롬프트 | 0 | 적응 전 기준 |
| L | 12개 제품으로 QLoRA 적응한 Qwen3-VL-4B(2B로 선별, 4B로 확인), 사전 포함 | 0 | 핵심 제안 |
| L-정의 없음 | L과 같으나 사전에서 정의 문장을 빼고 이름만 제공. 2B로 잰다(변경 기록 2026-11-02) | 0 | Q3 |
| Z-2B | Qwen3-VL-2B zero-shot(bf16), 2B LoRA와 같은 기저 모델. 적응 효과를 모델 크기와 분리해 보는 탐색적 비교(변경 기록 2026-11-02) | 0 | 해석용 |
| B-교차 | 12개 제품의 결함 이미지로 공통 키를 분류하는 로지스틱 회귀(DINOv2 특징 + 이상 맵 통계). 새 제품에서는 사전에 있는 공통 키 중에서만 고른다. 고유 유형은 원리상 맞힐 수 없다 | 0 | 라벨 0장 비-VLM |
| B-CLIP | 이미지(또는 crop) 임베딩과 "제품 + 정의" 텍스트 임베딩의 코사인 유사도로 유형 선택(SigLIP 또는 CLIP) | 0 | 글을 읽는 비-LoRA 기준 |
| B-k장 | 새 제품 결함 유형당 k장(k = 1, 2, 5, 10)으로 학습한 로지스틱 회귀(DINOv2 특징). 표본 추출 20회 반복, 평가는 뽑지 않은 이미지 | 유형당 k | Q2 |
| B-전체 | 새 제품 라벨 전부로 5-fold 교차 검증한 로지스틱 회귀 | 전부 | Q4 대조군 |

B-k장과 B-전체는 뽑은 이미지를 평가에서 뺀다. VLM과 비교할 때는 같은 이미지 집합으로 채점한다.

## 6. 지표

- 주 지표: 유형 정확도. 결함 이미지 중 예측 키가 정답 키와 같은 비율을 제품별로 구하고 toothbrush를 뺀 14개 제품을 평균한다(제품마다 장수가 달라 이미지 평균은 큰 제품에 끌린다).
- 보조 지표: 유형별 macro-F1, 공통 유형과 고유 유형으로 나눈 정확도, 정상 판정률(test/good에 "정상"이라 답한 비율), 출력 형식 준수율, 생성 시간과 최대 VRAM.
- 신뢰구간: 두 방법이 같은 이미지에 낸 정오(0/1)를 짝지어 제품 층화 부트스트랩 10,000회로 차이의 95% 구간을 구한다(이하 "쌍대 구간"). 유의성은 McNemar 정확 검정, 여러 비교는 Holm 보정.

## 7. 가설과 판정 기준

| 가설 | 내용 | 지지 기준 |
|---|---|---|
| H1(주) | 라벨 0장에서 L이 비-VLM 기준선보다 낫다 | L의 유형 정확도가 B-교차와 B-CLIP 중 높은 쪽보다 10%p 이상 높고, 쌍대 구간이 0을 제외 |
| H2 | 교차점 k는 3 이상이다 | B-k장의 20회 평균 정확도가 L 이상이 되는 가장 작은 k가 3 이상(k = 1, 2에서 L이 높음). k = 10에서도 못 넘으면 "10 초과" |
| H3 | L은 정의 문장을 읽는다 | 정의를 빼면 고유 유형 정확도가 10%p 이상 떨어지고 쌍대 구간이 0을 제외하되, 공통 유형에서는 구간이 0을 포함 |
| H4(대조) | 라벨이 충분하면 분류기가 낫다 | B-전체의 정확도가 L 이상. VLM에 불리한 예상을 미리 적어 둔다 |
| H5 | 적응은 형식과 정상 판정을 함께 배운다 | L의 형식 준수율 95% 이상, 정상 판정률이 Z보다 높고 쌍대 구간이 0을 제외 |

판정에 쓰는 L은 4B 모델이다. 2B는 선별용이며 2B 결과로 가설을 판정하지 않는다.

### 결과별 해석

| 결과 | 서술 |
|---|---|
| H1 지지, H2 지지, H4 지지 | VLM의 이득은 라벨이 유형당 두 장 모이기 전의 콜드 스타트 구간에 있다 |
| H1 지지, H2 기각 | 이득은 있으나 라벨 한두 장이면 사라진다. 사전만으로 시작할 수 있다는 점이 남는 가치다 |
| H1 기각 | 결함 어휘의 언어 전이는 이 모델 크기와 데이터에서 비-VLM 기준선을 넘지 못했다. 음성 결과로 보고한다 |
| H3 기각(정의 효과 없음) | 모델은 유형 이름과 시각 사전 지식으로 답한다. 정의 문장은 이 과제에서 읽히지 않았다 |
| H4 기각(L이 전체 라벨 분류기보다 높음) | 예상 밖의 결과이므로 사후 분석으로만 다루고 주장하지 않는다 |

## 8. 절차와 중단 조건

| 단계 | 내용 | 중단 조건 |
|---|---|---|
| 0 | 인덱스, 사전, 분할, 이 문서, 프롬프트 템플릿을 커밋 | |
| 1 | 라벨 0장 기준선(B-교차, B-CLIP), B-k장, B-전체, Z를 5-fold 전부 계산 | |
| 2 | 2B LoRA를 5-fold로 학습해 입력 구성(crop, 참조, 정의)을 선별 | 2B의 유형 정확도가 1단계 비-VLM 최고치를 넘지 못하면 4B로 가지 않고 음성 결과로 보고 |
| 3 | 4B QLoRA 5-fold(L). L-정의 없음은 2B로 대체하고 Z-2B를 추가(변경 기록 2026-11-02). 예산이 남으면 L만 seed 2개 추가 | |
| 4 | 표, 그림, 실패 사례 분석, 노션 페이지 | |

학습 설정(LoRA rank, 학습률, epoch)은 학습 제품 안의 검증 분할로만 고르고, 평가 제품의 결과를 본 뒤에는 바꾸지 않는다.

### 사전학습 노출 탐침

Qwen3-VL의 사전학습 데이터에 MVTec AD가 포함됐을 수 있다. 그 경우 Z의 성능이 높게 나오고 "언어 전이"라는 해석이 약해진다. 0단계에서 Z에 사전 없이 "이 이미지의 결함을 한 단어로 말하라"고 물어 폴더 이름(영어)을 그대로 맞히는 비율을 재고, 결과와 함께 보고한다. 이 탐침은 해석을 위한 것이며 가설 판정에는 쓰지 않는다.

## 9. 예산

로컬 GPU 1장(RTX 3060 12GB) 기준이다. GPU를 혼자 쓰는 20 step 스모크 실측으로 2B LoRA(이미지 3장 입력, gradient checkpointing 사용)는 표본당 약 1.6초, 생성은 배치 8에서 장당 약 1.3초였다. gradient checkpointing을 끄면 VRAM이 10.8GB로 늘고 더 느려져 쓰지 않는다. 학습 표본은 fold당 1,121~1,195장이고 epoch 3이므로 2B는 입력 구성에 따라 run당 약 1~1.8시간이고, 네 구성 × 5-fold는 약 26시간이다. 4B QLoRA는 GPU를 나눠 쓴 스모크에서 표본당 약 6초였고 fold당 4~6시간, 3단계 두 설정 5-fold는 약 40~60시간으로 추정한다. 최대 VRAM은 2B 학습 5.0GB와 생성(배치 8) 7.5GB, 4B 학습 5.1GB와 생성(배치 4) 6.5GB였다. 체크포인트는 50 step(약 15분)마다 저장한다.

## 10. 한계(미리 적어 두는 것)

- 제품 수가 15개라 fold 간 분산이 크다. 제품 평균 정확도의 구간은 넓게 나올 것이다.
- 공통/고유 구분이 키 일치라서 뜻이 비슷한 유형의 전이를 놓친다.
- 결함 사전은 한 사람이 썼다. 정의 문장의 질이 결과를 좌우할 수 있으므로 문장을 바꾼 변형은 탐색적으로만 본다.
- 사전학습 노출을 완전히 배제할 수 없다.

## 변경 기록

- 2026-11-01 초안 작성, 인덱스로 장수 확정, toothbrush 제외 규칙 추가.
- 2026-11-01 (모델 결과 전) B-k장의 추출 규칙을 구체화: 유형의 장수가 k 이하이면 장수에서 하나를 뺀 만큼만 뽑아 적어도 한 장은 평가에 남긴다. B-CLIP의 이미지 변형(전체 또는 crop)은 fold마다 학습 제품의 정확도로 고른다. 비-VLM 기준선은 결함 유형 분류만 하고 정상 판정은 하지 않는다(H5는 VLM끼리의 비교다).
- 2026-11-01 (비-VLM 기준선 결과를 본 뒤, VLM 결과 전) Z는 L과 같은 NF4 양자화 기저 모델로 돌린다. 12GB에서 bf16 4B 생성이 빠듯하고, 적응 효과를 양자화 효과와 분리해 보기 위해서다. 2단계의 입력 구성 선별 기준은 2B의 평가 fold 유형 정확도 제품 평균이며 검증 분할 정확도를 함께 기록한다. 2B는 선별용이고 가설 판정은 4B로만 한다는 원칙은 그대로다. 2단계는 네 입력 구성(전체, crop 없음, 참조 없음, 검사 이미지만)을 5-fold 전부 돌리고, 정의 없는 사전의 2B 변형은 예산이 남을 때만 돌린다. 예산 절을 GPU 단독 사용 실측으로 고쳤다.
- 2026-11-02 (2B 세 구성의 5-fold 결과를 본 뒤, 4B 적응 결과 전) 3단계 범위를 줄였다. L-정의 없음(4B)은 돌리지 않고, 정의 문장의 효과(Q3, H3)는 2B 정의 없음 변형 5-fold로 잰다. 이유는 예산이다. 4B QLoRA는 fold당 4~6시간이 들어 두 설정을 다 돌리면 50시간 안팎이다. 2B 네 입력 구성의 제품 평균이 47~52 사이에 모여 있어 입력 구성 효과를 4B에서 다시 잴 필요는 낮다고 보았다. H3를 판정하는 모델이 4B에서 2B로 바뀌므로 그 결과는 선별 모델 기준임을 표에 적고 해석의 한계로 남긴다. 2B zero-shot(Z-2B, bf16, 2B LoRA와 같은 기저 모델) 5-fold를 추가한다. 2B LoRA의 제품 평균이 4B zero-shot과 거의 같아(51.6과 49.6), 적응 효과를 모델 크기 효과와 분리해 보려는 탐색적 비교이며 가설 판정에는 쓰지 않는다. 4B QLoRA의 입력 구성은 8절의 선별 기준대로 2B 평가 fold 제품 평균이 가장 높은 구성을 쓴다. 가설과 판정 기준은 바꾸지 않았다.
- 2026-11-02 (2B 네 구성의 결과를 본 뒤, 4B 적응 결과 전) 8절의 기준으로 4B QLoRA의 입력 구성을 골랐다. 2B 평가 fold 유형 정확도 제품 평균은 참조 없음 51.9, 전체 입력 51.6, crop 없음 50.1이고 검사 이미지만은 4 fold 기준 47.4였다. 차이는 작지만 기준대로 가장 높은 참조 없음(검사 이미지, crop, 사전)을 L의 입력으로 쓴다. Z는 전체 입력으로 이미 돌렸으므로, L과 같은 참조 없음 입력으로 Z를 다시 돌려 적응 전후 비교가 입력 차이와 섞이지 않게 한다. Z-2B도 같은 입력을 쓴다. 전체 입력 Z 결과는 참고로 함께 보고한다.
